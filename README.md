# Study Lab
A simple tool for studying.
-**Quiz** - There are quizes that you make to test yourself
-**Flash Cards**-Match terms with their meanings
-**Typing Practice**- Type out notes to help you remember the topics and material

## How to use
1. Use my demo link
2. Click what you want to do
3. Do it!!!!
